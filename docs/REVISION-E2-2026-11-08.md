## Reproducción local

El procedimiento estándar está en el README. Las variables `TEST_*` y condiciones del contrato se documentan en los README de servicios y [COMUNICACION-HOSPITAL](COMUNICACION-HOSPITAL.md). Sin esas variables, las pruebas correspondientes se omiten.

En esta computadora Windows bloquea 58983. Para reproducir la excepción local, crear `tmp/revision-e2/compose.override.yaml` con:

```yaml
services:
  solr:
    ports: !override
      - "127.0.0.1:18983:8983"
```

Ejecutar desde la raíz:

```powershell
docker compose -f compose.yaml -f tmp/revision-e2/compose.override.yaml up -d --build --wait --wait-timeout 300
$env:TEST_SOLR_URL = "http://127.0.0.1:18983/solr/vehicles"
go run ./cmd/smoke -history
go run ./cmd/checkshared -url http://127.0.0.1:8080 -env .env
```

La superposición requiere Compose compatible con `!override`. Las pruebas restantes necesitan además sus variables privadas de PostgreSQL, MongoDB y Redis. No se imprimen ni versionan las cadenas con contraseñas. Para detener, usar el mismo par de archivos y `stop`; no borrar los volúmenes existentes. Los entornos de la revisión quedaron detenidos.
